# Changelog

## 4.2.1 — Clinical Angles
- Hip: signed flexion (+) / extension (-).
- Knee: signed flexion (+) / hyperextension (-).
- Ankle: dorsiflexion (+) / plantarflexion (-), neutral approximately 0°.
- Added left/right-facing sagittal direction handling.
- Preserved existing V4.2 output column names for compatibility.
- Added explicit clinical-angle labels and metadata.
